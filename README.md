# Manuale di Postino

Guida per chi usa Postino ogni giorno: creare liste e iscritti, preparare e inviare
newsletter, leggere i risultati, gestire la galleria e lo spazio.

Per l'installazione e la configurazione tecnica vedi la documentazione del progetto;
per le funzioni riservate al super admin c'è il manuale dedicato.

## Convenzioni

- I nomi dei menu sono quelli della barra laterale.
- Un **namespace** è un contenitore di liste, campagne e media, con i suoi utenti.
- Le parti marcate *(in preparazione)* sono in lavorazione: non descrivono funzioni definitive.
